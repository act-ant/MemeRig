# Package built-in templates

Move built-in template sources into a private workspace package. Keep the current official registry URL and support independent Git registries for specs and workflows. Deliver a tested local build archive and installation commands.

## Acceptance

- The packed CLI can initialize the three bundled starter specs and native workflow without network access.
- A separate Git registry can supply a spec and workflow from a tag.
- Generated paths and template bytes preserve existing project compatibility.
- Deliver a selective commit and downloadable local package.
